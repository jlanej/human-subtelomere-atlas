Guided tour: see the molecules

Real DNA molecules from public sequencing data, in a genome browser, with nothing to install. Use Next (or the arrow keys). Each stop loads its own data; drag to pan, scroll or use + / − to zoom. Prefer a static picture? The whole argument in one figure.

      The whole argument in one figure

      What the tracks are
      • assembly blocks (catalogue): the atlas's labels for the person's own chromosome end (telomere; blocks named after the CHM13 end they match best; home = the chromosome's own sequence).
      • diagnostic sites (claim model): the pre-registered claim model (criteria v1): single-base sites where the donor and comparator CHM13 ends differ (orange on the donor end, blue on the comparator end; the label gives both letters), sequence found only in one of them, and their shared blocks in grey (FAQ, verify).
      • assembly blocks → CHM13: each block of the person's assembly placed on the reference end its label names.
      • molecules → own assembly: whole molecules aligned to the person's own chromosome ends.
      • molecules → CHM13 (cut at switch): each molecule cut at its switch interval (criteria v1); part 1 (telomere to switch) aligned to the donor end, part 2 to the recipient end. Names end in /part1, /part2.
      • All reference panels are in tip frame: position 1 is the telomeric tip; q-arm ends are shown reverse-complemented so that every panel reads from the telomere inward. Data and the script that made them: website/tour_build.py.
