Definitions: analysis forms vs catalogue revision 2

The three analyses (telomere_cis, junctions, allele_ages) used the earlier per-window best-end form calls (a terminal block called by the single best CHM13 end of a 20 kb window, e.g. 20q>3q; column prior_form of ends.tsv). Catalogue revision 2 labels blocks from per-base identity tracks, applies the home rule and groups near-identical CHM13 ends into paralog families (e.g. 20q>PF04, PF04 = 3q/19p), so analysis counts are not directly comparable with revision-2 S20, form or nativity counts.
