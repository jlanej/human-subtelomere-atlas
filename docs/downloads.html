Site data

The arm pages read compact per-arm data files (data/arms/<arm>.js, derived from the release tables); every arm page can export its filtered member table as TSV. The allele search index is data/alleles_index.json.

Analysis results

  • analyses/telomere_cis/results/ (Telomere length and the terminal allele (H1))
  • analyses/junctions/results/ (Mechanism at junctions (H2))
  • analyses/allele_ages/results/ (Population distribution, origin and age)
