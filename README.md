# human-subtelomere-atlas (in preparation)

A validated, queryable catalogue of human chromosome-end (subtelomere) alleles from HPRC Release 2, HG002 Q100 and CHM13.
Layout: `pipeline/` catalogue build, `data/` release tables and representative sequences, `atlas/` query tool, `tests/`,
`analyses/` hypothesis tests, `docs/` GitHub Pages site, `literature/` review, `work/` large intermediates (git-ignored).
